개인정보 처리방침

시행일: 2026년 10월 2일 · 적용 대상: 홀노트 1.0.0

홀노트(이하 “앱”)는 로그인 없이 사용하는 개인 골프 스코어북입니다. 운영자는 홀노트 개발자(ssadakk)이며, 이 방침은 앱의 기록 처리 방식과 지원 문의 시 제공되는 정보의 처리 방법을 설명합니다.

1. 기기에 보관하는 정보와 목적

이용자가 입력한 다음 정보를 기기 내부에 보관합니다.

  • 라운드 날짜와 골프장 이름
  • 홀별 파·온·퍼트, 해저드·OB 표시와 자유 메모
  • 라운드 진행·종료 상태와 홀별 완료 상태
  • 기록을 구분하기 위한 식별자와 생성·수정 시각

이 정보는 기록 저장·수정·조회, 타수와 퍼트 합계 계산, 작성 중인 기록의 복원에 사용합니다. 기록 식별자는 앱의 기록을 구분하기 위한 값이며 광고나 이용자 추적에 사용하지 않습니다.

2. 서버 전송과 제3자 제공

앱은 라운드 기록을 개발자 서버로 전송하지 않습니다. 현재 버전에는 계정, 서버 저장·동기화, 광고 또는 분석용 추적 기능이 없으며, 개발자가 기기의 라운드 기록을 조회하거나 제3자에게 제공하지 않습니다. 핵심 기록 기능은 인터넷 연결 없이 사용할 수 있습니다.

3. 기록 보관·수정·삭제

기록은 이용자가 삭제하기 전까지 기기에 보관합니다. 진행 중이거나 종료한 라운드의 홀 기록과 메모를 앱에서 수정할 수 있습니다. 라운드 결과 화면의 삭제 버튼으로 해당 라운드와 연결된 홀 기록·메모를 삭제할 수 있으며, 앱에는 삭제한 기록을 복원하는 기능이 없습니다.

앱 삭제나 기기 분실 시 기록을 잃을 수 있습니다. 앱 자체의 백업·동기화 기능은 제공하지 않습니다. 운영체제의 기기 백업에 기록이 포함되는지는 이용자의 설정과 운영체제 정책에 따라 달라질 수 있습니다. 개발자는 기기에만 저장된 기록을 대신 복구하거나 삭제할 수 없습니다.

4. 지원 문의 시 제공하는 정보

이용자가 이메일로 문의하면 회신 이메일 주소, 문의 내용과 직접 첨부한 화면·기기 정보 등을 개발자가 받습니다. 이 정보는 문의 답변과 문제 해결에 필요한 범위에서 사용하고, 처리 목적을 달성하여 더 이상 필요하지 않으면 삭제합니다. 법령상 보관 의무가 있는 경우에는 해당 의무에 따릅니다.

문의 정보의 열람·정정·삭제는 아래 이메일로 요청할 수 있습니다. 문의할 때 비밀번호나 문제 해결에 필요하지 않은 개인정보는 보내지 마세요. 골프장 이름이나 메모가 보이는 화면을 첨부할 때는 공개하고 싶지 않은 내용을 가려 주세요.

5. 외부 웹사이트와 이메일 서비스

앱에서 정책·지원 링크를 열면 외부 웹사이트인 GitHub Pages에 접속합니다. 이때 라운드 기록은 웹사이트로 전달되지 않습니다. 웹사이트 접속과 이메일 전송 과정에서 해당 서비스가 처리하는 정보에는 각 서비스의 개인정보 처리방침이 적용됩니다.

6. 방침의 변경

앱의 기능이나 정보 처리 방식이 변경되면 이 페이지에 변경된 방침을 게시하고 시행일을 갱신합니다.
