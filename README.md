# 앱 정책

앱별 개인정보 처리방침과 지원 페이지를 관리하는 저장소입니다.

## 구조

각 앱의 정책 문서는 `apps/<앱 이름>/` 아래에 둡니다.

```text
apps/
├── hermes-personal/
│   ├── index.html
│   ├── privacy.html
│   └── support.html
├── holenote/
│   ├── index.html
│   ├── privacy.html
│   └── support.html
└── tokbaro/
    ├── index.html
    ├── privacy.html
    └── support.html
```
